# ステージ形式

## 方針

最小試作品では、ステージは文字列配列としてコード内に持つ。

外部ファイル読み込みは実装してもしなくてもよい。

Codexが扱いやすい方法を選んでよい。

## 記号

| 記号 | 意味 |
|---|---|
| `#` | 壁 |
| `.` | 床 |
| 半角スペース | 床 |
| `P` | プレイヤー開始位置 |
| `S` | 電源 |
| `W` | ワイヤ床 |
| `L` | ランプ |
| `A` | ANDブロック |
| `O` | ORブロック |

## 読み込みルール

各行の文字数が違う場合は、最も長い行を盤面幅として扱う。

短い行の不足分は床として扱ってよい。

`P` はプレイヤー開始位置として読み込み、そのマス自体は床として扱う。

`A` と `O` はブロック開始位置として読み込み、そのマス自体は床として扱う。

`S`、`W`、`L` は床属性を持つマスとして扱う。

## 初期ステージ案

このステージは、動作確認用の仮ステージである。

遊びやすさより、実装確認を優先する。

```text
###########
#    L    #
#    W    #
# S  W    #
#    W    #
#   A     #
#         #
# P       #
###########
```

```text
###########
#    L    #
#    W    #
# S  W    #
#         #
#   O     #
#         #
# P       #
###########
```

## 複数ブロック確認用ステージ案

```text
#############
#     L     #
#     W     #
# S W W W S #
#           #
#    A O    #
#           #
# P         #
#############
```

## 注意

上のステージは、必ずしも完成した良問ではない。

最小試作品では、ステージを遊びやすくすることより、ルールが実装されていることを優先する。

Codexは、完了条件を確認しやすくするために、追加のテストステージをコード内に持ってもよい。
