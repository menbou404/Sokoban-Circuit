# ルール詳細

## 基本構造

ゲームはマス目で進行する。

すべての物体は整数のマス目座標を持つ。

プレイヤーとブロックは、常に1つのマスの中央に存在する。

半マスの状態は存在しない。

## マスの種類

| 記号 | 意味 |
|---|---|
| `#` | 壁 |
| `.` | 床 |
| 半角スペース | 床 |
| `P` | プレイヤー開始位置 |
| `S` | 電源 |
| `W` | ワイヤ床 |
| `L` | ランプ |
| `A` | ANDブロック |
| `O` | ORブロック |

## 壁

壁にはプレイヤーもブロックも入れない。

## 床

床にはプレイヤーが入れる。

床にはブロックを置ける。

電源、ワイヤ、ランプも床の一種として扱う。

## プレイヤー移動

プレイヤーが移動を試みたとき、次の順で判定する。

1. 移動先が盤面外なら移動しない
2. 移動先が壁なら移動しない
3. 移動先にブロックがあるなら、ブロックを押せるか調べる
4. ブロックの押し先が空いていれば、ブロックとプレイヤーを1マス動かす
5. 移動先にブロックがなければ、プレイヤーだけ1マス動かす
6. 移動が成立した場合だけ、信号を再計算する

## ブロック移動

ブロックはプレイヤーに押されたときだけ動く。

ブロックは1手につき1マスだけ動く。

ブロックの押し先が次のいずれかなら押せない。

- 盤面外
- 壁
- 他のブロックがあるマス

## 論理ブロック共通仕様

ANDブロックとORブロックは、どちらも移動できるブロックである。

最小試作品では、ブロックの向きは固定する。

入力方向は左と右。

出力方向は上。

つまり、ブロックの左隣と右隣が入力、ブロックの上隣が出力になる。

## ANDブロック

ANDブロックは、左入力と右入力の両方がオンのときだけ、上へ信号を出す。

左入力または右入力のどちらかがオフなら、信号を出さない。

## ORブロック

ORブロックは、左入力と右入力の少なくとも片方がオンなら、上へ信号を出す。

左入力と右入力の両方がオフなら、信号を出さない。

## 信号の考え方

信号はマス単位でオンまたはオフを持つ。

信号は、毎手ごとにゼロから再計算する。

前の手の信号状態を残してはいけない。

## 信号の伝わり方

電源マスは常にオンになる。

ワイヤ床は、上下左右に隣接するオンのマスから信号を受け取る。

ワイヤ床がオンになると、上下左右に隣接するワイヤ床へ信号を伝える。

ランプマスは、上下左右に隣接するオンのマスから信号を受け取ったらオンになる。

AND/ORブロックは、入力方向のマスがオンかどうかを見て出力を決める。

## 信号計算手順

毎回、次の順番で再計算する。

1. すべての通電状態を空にする
2. 電源マスを通電状態にする
3. 通電済みマスからワイヤへ信号を広げる
4. AND/ORブロックを評価する
5. 出力条件を満たすブロックの出力先マスを通電状態にする
6. 新しく通電したマスから再びワイヤへ信号を広げる
7. 通電状態に変化がなくなるまで繰り返す
8. ランプが通電しているか確認する

## 無限ループ対策

信号計算は、変化がなくなれば終了する。

念のため、最大反復回数を設ける。

推奨値は、盤面のマス数の4倍以上とする。

最大反復回数に達した場合は、それ以上計算せず、デバッグ出力で分かるようにする。
