# 段階実装用プロンプト

一括実装で失敗する場合は、次の順番でCodexに依頼してください。

## 1. 土台作成

```text
Markdown仕様書をすべて読んでください。
まずGodot 4.xプロジェクトの土台だけを作ってください。
ファイル構造、シーン構成、クラス構成はあなたが判断してください。
外部アセットは使わないでください。
この段階では、ゲーム画面が起動し、ステージ文字列を読み込んで壁、床、プレイヤー、ブロックを簡易表示できればよいです。
```

## 2. 移動と押し判定

```text
前回の実装を維持したまま、プレイヤー移動とブロック押しを実装してください。
上下左右に1マス移動し、壁と盤面外には入れないようにしてください。
ブロックは押し先が空いている場合だけ1マス押せるようにしてください。
物理エンジンではなく、Vector2iのマス目座標で判定してください。
```

## 3. 電源、ワイヤ、ランプ

```text
前回の実装を維持したまま、電源、ワイヤ、ランプの信号計算を追加してください。
電源は常にオン、ワイヤは上下左右に信号を伝え、ランプに信号が届いたら点灯するようにしてください。
プレイヤーまたはブロックが動くたびに、信号をゼロから再計算してください。
```

## 4. AND/ORブロック

```text
前回の実装を維持したまま、ANDブロックとORブロックの回路判定を追加してください。
入力方向は左と右、出力方向は上で固定してください。
ANDは左右両方の入力がオンの場合だけ上へ出力してください。
ORは左右どちらか一方以上の入力がオンの場合に上へ出力してください。
```

## 5. クリア、リセット、デバッグ

```text
前回の実装を維持したまま、CLEAR表示、Rキーリセット、デバッグ表示を追加してください。
デバッグ表示には、手数、プレイヤー座標、ブロック数、通電中マス数、クリア済みかどうかを表示してください。
最後にACCEPTANCE_TESTS.mdを確認し、不足があれば修正してください。
```
